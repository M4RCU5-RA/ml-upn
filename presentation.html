Sistema Inteligente de Atención al Estudiante con Machine Learning Local

Servidor en Django, motor de procesamiento de lenguaje natural (NLP) on-premise y widget de chat embebible para consultas universitarias 24/7.

🏛️ Institución: Universidad Privada del Norte (UPN)
⚙️ Arquitectura: Django + Scikit-Learn + Vanilla JS
💰 Costo: $0.00 USD (100% Open Source)
🎯 Justificación del Proyecto

Problemática y Objetivos Académicos

⚠️
Problemas Detectados en la Atención
  • Colapso en matrículas: Cientos de consultas repetitivas sobre fechas, límites de créditos y turnos.
  • Horario limitado: La oficina de asuntos académicos solo atiende en horario de oficina.
  • Dispersión de información: Cronogramas, horarios de docentes y trámites en diferentes PDFs y enlaces.
🎯
Objetivos del Sistema
  • Automatización Inmediata: Respuestas precisas en menos de 100ms mediante NLP.
  • Gestión Centralizada: Panel de control administrativo para que el personal actualice información sin programar.
  • Integración Universal: Widget embebible en cualquier web de la universidad con una sola línea de código.
🏗️ Diseño de Software

Arquitectura del Sistema

🖥️
Backend & Admin (Django)

Django 5 + Django REST Framework con CORS habilitado.

  • Panel Django Admin para gestión de FAQs, cursos y fechas.
  • Endpoints REST para chat, configuración y feedback.
  • Persistencia y logs con SQLite / PostgreSQL.
🧠
Motor ML / NLP Local

Procesamiento de texto offline sin costo de APIs externas.

  • TF-IDF Vectorizer + N-Grams (1 a 3).
  • Similitud de Coseno + Boosting por entidades.
  • Conector extensible a Ollama (Llama 3.2).
💬
Widget JavaScript Embebido

Componente web aislado e integrable en cualquier sitio.

  • Desarrollado en Vanilla JS + Shadow DOM.
  • Formateo Markdown automático y tablas interactivas.
  • Chips dinámicos de sugerencias y feedback 👍/👎.
🔬 Inteligencia Artificial & NLP

¿Cómo Funciona el Motor NLP Local?

⚙️
Pipeline de Procesamiento
  • Normalización Lingüística: Eliminación de diacríticos/tildes, caracteres especiales y normalización en minúsculas en español.
  • Filtrado de Stopwords: Remoción de palabras vacías no informativas preservando términos clave.
  • Vectorización TF-IDF Multigramas: Conversión del corpus universitario y de la consulta del alumno a matrices vectoriales numéricas.
  • Re-ranking por Entidades: Bonificación cuando se detectan nombres de cursos, docentes o trámites específicos.
💻
Cálculo de Similitud Vectorial
# Vectorización de la pregunta query_vec = vectorizer.transform([norm_query]) # Similitud de Coseno con el corpus similarities = cosine_similarity(query_vec, tfidf_matrix) # Ranking con boosting por entidad score = tfidf_score * priority + entity_bonus

Permite tiempos de respuesta de < 50 ms sin depender de tarjetas GPU pesadas ni costos de API.

🔌 Integración Frontend

Integración Rápida con JavaScript

🛡️
Ventajas del Shadow DOM

El widget vive dentro de un Shadow Root aislado del DOM principal:

  • Sin colisiones CSS: Los estilos de la página universitaria o intranet no deforman el chat.
  • Cero dependencias: Funciona en Vanilla JS sin requerir React, Vue ni librerías pesadas.
  • Totalmente Responsive: Adaptable a smartphones, tablets y pantallas de escritorio.
📦
Código de Integración (1 sola línea)

Cualquier sistema web puede incluir el asistente añadiendo:

<!-- Widget de Asistente IA --> <script src="https://servidor.edu/static/widget/chat-widget.js" defer></script>

El script automáticamente genera el botón flotante, la ventana modal y se conecta a la API de Django.
